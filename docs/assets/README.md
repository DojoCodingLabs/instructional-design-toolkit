# Banner

`banner-light.svg` y `banner-dark.svg` se generan a partir de `banner.toml` con
[dojo-readme-kit](https://github.com/DojoCodingLabs/.github/tree/main/kit), en el sistema visual de
[dojocoding.io](https://dojocoding.io). Para cambiar el banner, editá `banner.toml` y ejecutá:

    uvx --from "git+https://github.com/DojoCodingLabs/.github#subdirectory=kit" dojo-banner docs/assets/banner.toml

`dojocoding-mark.png` es la marca oficial de Dojo Coding, usada en el pie del README.
